# Ejercicio To-Do

- Ejercicio práctico de hacer una interfaz donde poder añadir tareas con una descripción y prioridad.

# Como funciona

- El programa permite crear tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Ver las tareas.
- Filtrar tareas según su prioridad.
- Exportar las tareas a un archivo de texto.

# Como se ejecuta

- Ejecutar la clase `Gestor`.
- Elegir una opción del menú.
- Al añadir una tarea se solicitará:
    - Descripción.
    - Prioridad (ALTA, MEDIA o BAJA).

# Implementacion

- Usa Java JDK 27.
- Utiliza `ArrayList` para almacenar las tareas.
- Gestión de la interfaz mediante `Scanner` y `System.out.println`.

# Prioridades

Cada tarea puede tener una prioridad:

- ALTA
- MEDIA
- BAJA
